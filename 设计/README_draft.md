## 🤔 The Problem

You're building with LangChain, LlamaIndex, CrewAI, or any AI agent framework. Something breaks. You copy the error, search everywhere — GitHub Issues, Discord, Stack Overflow, Reddit — wasting hours piecing together a fix from scattered threads.

**CyberHuaTuo** is an open-source knowledge base that aggregates these problems and their battle-tested solutions in one place. Like [OpenClaw](https://github.com/openclaw/openclaw) for agent capabilities, CyberHuaTuo is for agent **problem-solving**.

你在用 AI Agent 框架开发，结果报错了。你复制错误信息到处搜——GitHub Issues、Discord、Stack Overflow、Reddit——花好几个小时才从零散的帖子里拼凑出解决方案。

**赛博华佗** 是一个开放的知识库，将这些问题和经过验证的解决方案聚合在一起。就像 OpenClaw 让大家共享 Agent 能力一样，CyberHuaTuo 让大家共享 **解决 Agent 问题的经验**。

## ✨ How It Works

Every case in CyberHuaTuo follows a structured format — **YAML metadata + Markdown body** — making it both human-readable and machine-parseable:

```yaml
---
id: "langchain-import-chatmodel-001"
title: "LangChain 0.3 升级后 ChatOpenAI 导入失败"
title_en: "ChatOpenAI import error after upgrading to LangChain 0.3"
framework: "langchain"
severity: "medium"
complexity: "simple"        # simple → moderate → complex → extreme
---

## 🏥 症状描述 / Symptom Description
...

## 🔍 错误信息 / Error Message
...

## 💊 药方 / Prescriptions
...
```

### 🏥 望闻问切 — Four Levels of Complexity

| Level | Complexity | What It Covers |
|-------|-----------|---------------|
| 🟢 | **Simple** | Import errors, missing configs, version mismatches |
| 🟡 | **Moderate** | API changes, environment conflicts, dependency chains |
| 🔴 | **Complex** | Memory leaks, async deadlocks, multi-agent coordination |
| ⚫ | **Extreme** | Race conditions, upstream bugs, multi-factor compound issues |

## 🚀 Quick Start

### Browse Cases

Just browse the [`cases/`](./cases/) directory on GitHub! Cases are organized by framework:

```
cases/
├── langchain/          # LangChain issues
├── llamaindex/         # LlamaIndex issues
├── crewai/             # CrewAI issues
├── mcp/                # MCP (Anthropic) issues
├── openai-sdk/         # OpenAI SDK issues
└── _cross-framework/   # Cross-framework issues
```

### Search Locally

```bash
git clone https://github.com/[owner]/CyberHuaTuo.git
cd CyberHuaTuo

# Search for a specific error
python tools/search.py "ChatOpenAI import error"

# Search by framework
python tools/search.py --framework langchain

# Search by tag
python tools/search.py --tag "breaking-change"
```

## 🤝 Contributing

CyberHuaTuo thrives on community contributions. Become a **坐堂医师 (Resident Doctor)**!

### Submit a New Case (挂号)

1. Fork this repo
2. Create a new case file:
   ```bash
   python tools/new-case.py    # Interactive wizard
   ```
   Or manually create a `.md` file following the [Data Format Spec](./设计/数据格式规范.md)
3. Validate locally:
   ```bash
   python tools/validate.py
   ```
4. Submit a Pull Request
5. After review → Merged ✅

### Improve an Existing Case (改良药方)

Found a better fix? Additional context? Just edit the case file and submit a PR.

### Quality Standards

Every case must include:
- ✅ Complete YAML metadata (all required fields)
- ✅ Clear symptom description and error message
- ✅ At least one verified prescription
- ✅ Pass `tools/validate.py` validation

See [CONTRIBUTING.md](./CONTRIBUTING.md) for full guidelines.
