### 品牌人格

**华佗** = 权威 + 温暖 + 神秘

- **权威感**：不是随便的问答平台，是"神医"级别的诊断准确率
- **温暖感**：开发者遇到 bug 已经很焦虑了，产品语气要像一个耐心的老中医
- **神秘感**：赛博朋克 + 东方古典的反差美学，给人"这东西不简单"的第一印象

## Logo 设计方向

### 概念 A：华佗剪影 + 电路

```
华佗的古典人物剪影，内部填充电路板纹理
底部配合霓虹绿色光晕
整体为圆形徽章，外圈有细电路线环绕
```

### 概念 B：药葫芦 + 数据流

```
传统中医药葫芦的轮廓
葫芦内部流淌着数据流（0101...）
葫芦口散发霓虹绿色光芒
极简线条风格
```

### 概念 C：针灸针 + 光标

```
一根针灸针化为代码光标 "|"
针尖发光，周围有诊断数据环绕
极度简洁，辨识度高
```

**推荐方案 B（药葫芦 + 数据流）**——辨识度最高，缩小后依然清晰，适合做 favicon。

### 视觉特效

1. **背景动画**: 深色底上漂浮的中医药材粒子（数字化风格），缓慢飘动
2. **输入框光效**: 聚焦时边框发出翡翠绿霓虹光晕，有微弱呼吸闪烁
3. **诊断过程动画**: 提交后依次显示望→闻→问→切四个步骤，每步有进度环
4. **痊愈庆祝**: 问题标记为痊愈时，有一个短暂的"✨药到病除✨"粒子爆炸效果
