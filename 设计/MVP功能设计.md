# 💊 CyberHuaTuo MVP 功能设计

## MVP 核心原则

> 用**最小代价**验证**最核心假设**：开发者是否愿意向开源知识库贡献 Agent 问题与解决方案？

## MVP 定义

CyberHuaTuo 的 MVP 是一个 **GitHub 仓库**，包含：
1. 高质量的种子数据（首批病例）
2. 清晰的数据格式规范
3. 完善的贡献指南
4. 自动化的 CI 校验
5. 本地搜索和管理工具

## MVP 功能清单

### P0 - 必须有（发布前完成）

#### 1. 📦 种子数据（首批病例库）

- 至少 **50 个高质量病例**，覆盖 3 个核心框架
- 覆盖 4 个复杂度级别（simple → extreme）
- 每个病例至少 1 个经过验证的药方
- 所有病例通过 CI 校验

#### 2. 📋 数据格式规范

- [x] YAML + Markdown 格式定义
- [x] 四级复杂度分级体系
- [x] JSON Schema 用于自动校验
- [x] 框架枚举值定义

#### 3. 🤝 贡献指南

- [ ] `CONTRIBUTING.md`：详细的贡献流程
- [ ] Issue 模板：新病例提交、改进药方
- [ ] PR 模板：标准化 PR 描述
- [ ] 行为准则 `CODE_OF_CONDUCT.md`

#### 4. 🔧 工具链

- [ ] `tools/new-case.py`：交互式创建新病例
- [ ] `tools/validate.py`：本地格式校验
- [ ] `tools/search.py`：本地搜索工具
- [ ] `tools/stats.py`：统计报告生成

#### 5. ⚙️ CI 自动化

- [ ] GitHub Actions 自动校验 PR 中的病例数据
- [ ] 自动生成 README 中的统计徽章

#### 6. 📄 README

- [ ] 项目介绍（中英双语）
- [ ] 使用方法
- [ ] 贡献指南快速入口
- [ ] 统计数据展示

### P1 - 应该有（发布后 1 个月内）

#### 7. 🌐 GitHub Pages 文档站

- 基于仓库数据自动生成可搜索的文档网站
- 支持按框架/标签/复杂度过滤浏览
- 技术：MkDocs 或 VitePress

#### 8. 📊 疫情通报（自动化统计）

- 各框架病例数量统计
- 复杂度分布图
- 最新贡献的病例
- 贡献者排行榜
- 通过 GitHub Actions 每日自动更新 `EPIDEMIC_REPORT.md`

#### 9. 🏷️ 框架索引文件

- 每个框架目录下的 `_index.md` 自动生成
- 包含该框架所有病例的索引表
- 按复杂度和标签分类

### P2 - 可以有（发布后 3 个月内）

#### 10. 💻 CLI 工具

- `pip install cyberhuatuo`
- 终端内搜索和查看病例
- 离线使用仓库数据

#### 11. 🔌 IDE 插件

- VS Code 扩展：在报错时自动搜索 CyberHuaTuo
- JetBrains 插件

#### 12. 🤖 GitHub Bot

- 在其他仓库的 Issue 中 @CyberHuaTuo 自动搜索匹配病例
- 自动回复可能的解决方案

## MVP 覆盖框架（种子数据范围）

| 优先级 | 框架 | 目标病例数 | 理由 |
|-------|------|-----------|------|
| 🔴 P0 | LangChain | 20+ | 问题密度最高，用户最多 |
| 🔴 P0 | MCP (Anthropic) | 15+ | 最新热门，文档不全 |
| 🔴 P0 | CrewAI | 10+ | 多 Agent 协作问题多 |
| 🟡 P1 | LlamaIndex | 10+ | RAG 场景问题多 |
| 🟡 P1 | OpenAI SDK | 10+ | 基础设施，影响面广 |
| 🟢 P2 | AutoGen / DSPy / etc. | 5+ | 社区自然扩展 |

## 种子数据策略

MVP 发布前需要 **至少 50 个高质量病例**，来源：

1. **从 GitHub Issues 精选**（30 例）：各框架高频、高赞问题
2. **个人开发经验**（15 例）：我们自己开发 Agent 时遇到的真实问题
3. **社区早期贡献者**（5 例）：邀请开发者朋友贡献

### 种子数据质量标准

每个病例必须包含：
- ✅ 完整的 YAML 元数据（所有必填字段）
- ✅ 清晰的症状描述和错误信息
- ✅ 至少一个经过验证的药方
- ✅ 通过 `tools/validate.py` 校验
- ✅ 标注了正确的复杂度级别
