## 签署方式 How to Sign

当你第一次向本项目提交 Pull Request 时，CLA Bot 会自动要求你签署本协议。
你只需在 PR 中回复以下内容即可完成签署：

When you submit your first Pull Request, the CLA Bot will automatically request
your signature. Simply reply with the following comment in the PR:

```
I have read the CLA Document and I hereby sign the CLA
```

**你只需要签署一次，之后的所有贡献将自动通过验证。**

**You only need to sign once. All future contributions will be automatically verified.**
